# underdog-web-challenge

## 프로젝트 소개 : 5일 웹 개발 챌린지

- HTML을 이용해서 반응형 프로필 페이지를 만들고 CSS로 디자인 했다.

## 사용한 기술 : HTML, CSS

## 주요 기능 또는 페이지 구성

1. 이름 + 한줄소개
2. 프로필 이미지 + 자기소개
3. 관심 분야 및 좋아하는 것
4. 배우고 싶은 것
5. 깃허브 링크 : 깃허브 프로필로 이동
6. 만든 사람

## 실행 방법

- 방법 1. 이 저장소를 복사(clone) / 다운로드 하기
  - `index.html` 파일을 웹 브라우저로 열기
- 방법 2. 배포 링크를 눌러서 열기

## 배포 링크

https://hyunjo-o.github.io/underdog-web-challenge/

## 작업하며 배운 점

- HTML 코드로 페이지를 만들기 위한 문법, 태그 등 기초 개념
- CSS코드 작성을 위한 기초 개념
- HTML과 CSS를 연결하는 방법
- git을 사용하는 방법

## 자기 소개

- 이름 : 김현주
- 지원 동기 : 웹/앱 개발이 적성과 진로에 맞는지 프로젝트를 진행하면서 경험해보고 기초를 다지고 싶어서 지원했습니다.
- 배우고 싶은 것 : 웹/앱 서비스 개발의 기획부터 배포까지 전체적인 프로젝트가 어떻게 이루어지는지와 이를 구현하기 위한 기초 개발 지식을 배우고 싶습니다.
